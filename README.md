# でんき日記 ⚡

スマートメーターの積算電力量を毎日手入力して、日次の電気使用量を記録・分析するアプリ。

自宅の電気使用量が **1日あたり 4.2kWh（2025年前半）→ 8.1kWh（2026年6月）** とほぼ倍増したため、その原因を追跡する目的で作った。契約先のマイページは月次データしか出さず、日次の粒度が取れないので、メーターの液晶を毎日読んで記録する。

## 使い方

1. 毎日ほぼ同じ時刻にスマートメーターの液晶を見る
2. 「積算電力量（kWh）」を読む
3. アプリに数値を入力する

前日との差分から、その日の使用量が自動で算出される。読み忘れた日は、日数で按分するか、読んだ日にまとめて計上するかを設定で選べる。

## 機能

| | |
|---|---|
| 日次記録 | 入力中に「この日は◯.◯◯kWh/日」をリアルタイム表示。マイナス値や平常の3倍超で警告 |
| イベント記録 | エアコン・来客・不在・霜取り・PC・家電のタグ付きメモ |
| グラフ | 日次kWh＋7日移動平均、月次kWh/日の推移、前年同月比 |
| 請求推計 | 実測日から検針期間の請求額を推計。月末を待たずに着地が読める |
| 料金シミュレータ | 使用量を動かして請求額と段階区分を確認 |
| アラート | 7日移動平均のしきい値超え、前年同期比の増加 |
| データ出力 | CSV 3種（記録・イベント・請求）＋ JSON バックアップ |

マスコットの **ビリすけ** は記録するたびに反応する。目標を下回った日、またはボルテージ満タンで「10まんワット」を撃つ。設定から自前の画像に差し替え可能。

## 判定の基準値

| 指標 | 値 |
|---|---|
| 元の定常値（2025年前半） | 4.2 kWh/日 |
| 2026年6月の実績 | 8.1 kWh/日 |
| 対策後の目標 | 6.3〜6.8 kWh/日 |
| 2026年9月分の判定ライン | 9.3以下なら霜取り成功 / 10.5前後なら効果なし |

**効果判定は必ず kWh/日 で行うこと。** 検針期間が28〜35日でバラつくうえ、2026年8〜10月分は国の支援で燃料費調整が下がるため、金額で見ると誤認する。

## 料金ロジック（KABU&でんき 一般家庭向け／関西電力 従量電灯A 相当）

| 区分 | 単価 |
|---|---|
| 最低料金（15kWhまで） | 522.58円 |
| 第1段階（15〜120kWh） | 20.20円/kWh（120kWh到達で2,121.00円） |
| 第2段階（120〜300kWh） | 25.59円/kWh |
| 第3段階（300kWh超） | 実績なし。28.86円/kWh を推定値として使用（設定で変更可） |

`請求額 = 最低料金 + 電力量料金 + 燃料費調整額 + 再エネ賦課金`

再エネ賦課金は 3.49円（〜2025/04分）→ 3.98円（2025/05分〜）→ 4.18円（2026/05分〜）。

シードした請求実績18か月分すべてで、この式が実際の請求額と円単位で一致することを確認済み。

## 技術

単一HTMLファイル。ライブラリ・ビルド・サーバー不要。グラフは手書きのSVG。

- データは **localStorage のみ**。外部への送信は一切なし
- Service Worker でオフライン動作
- Web App Manifest でホーム画面にインストール可能

localStorage は端末のブラウザ内にしか残らない。機種変更やブラウザのデータ削除で消えるため、**設定 → 全部バックアップ** を定期的に。

## ファイル

```
index.html               アプリ本体（これ1つで動く）
manifest.webmanifest     PWA マニフェスト
sw.js                    Service Worker（オフライン用）
icon-src.svg             アイコン元データ
icon-*.png               各サイズのアイコン
```

アイコンを変えたい場合は `icon-src.svg` を編集し、Chrome のヘッドレスで書き出す。

```bash
chrome --headless --window-size=512,512 --screenshot=icon-512.png icon-src.svg
```
